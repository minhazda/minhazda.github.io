End-to-end demand-forecasting MLOps: LightGBM beating a naïve seasonal baseline by 40.8% MAE, typed and tested, containerised, with Prometheus metrics and Evidently drift monitoring — deployed keylessly through Workload Identity Federation.

Step 1 — wake the container (this is part of the demo)

This service runs with min-instances = 0: when nobody is using it, it costs exactly nothing. The trade-off is a cold start on the first request — watch it happen live:

What's under the hood

  • Baseline-anchored: the model earns its deploy by beating a seasonal-naïve baseline — 40.8% lower MAE, 47.3% lower RMSE. No naked accuracy claims.
  • Time-safe validation: chronological splits only — no shuffled leakage of the future into training.
  • Drift monitoring: Evidently watches feature and prediction drift; MLflow tracks every training run.
  • Keyless CI/CD: GitHub Actions deploys to Cloud Run through Workload Identity Federation — no long-lived credentials.
